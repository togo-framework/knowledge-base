# knowledge-base — docs

A managed knowledge base for togo: ingest, chunk, embed, hybrid-search, and
scheduled crawl with change detection.

- **Install:** `togo install togo-framework/knowledge-base`
- **Marketplace:** https://to-go.dev/plugins/knowledge-base
- **Source:** https://github.com/togo-framework/knowledge-base

See [usage.md](usage.md) for the Go + REST API, embeddings, and crawling.
